# Estrutura do Planner no Notion

O Planner é composto por quatro bases relacionadas. Os nomes podem ser adaptados, mas as relações devem ser preservadas.

## 1. Objetivos

| Propriedade | Tipo | Uso |
|---|---|---|
| Nome | Título | Identificação do objetivo |
| Resultado esperado | Texto | O que precisa mudar ao final |
| Status | Seleção | Ideia, Planejando, Em execução, Concluído, Pausado |
| Data de início | Data | Início do ciclo |
| Data final | Data | Limite do ciclo |
| Prioridade | Seleção | Alta, Média, Baixa |
| Indicador principal | Texto | Evidência usada para acompanhar o objetivo |
| Ações | Relação | Ligação com Plano de ação |
| Revisões | Relação | Ligação com Revisões |

## 2. Plano de ação

Campos recomendados: Ação, Objetivo relacionado, Etapa, Status, Data planejada, Prioridade, Esforço estimado, Dependência, Critério de conclusão e Observações.

## 3. Obstáculos e alternativas

Campos recomendados: Obstáculo, Objetivo relacionado, Probabilidade, Impacto, Sinal de alerta, Alternativa planejada, Status e Próxima resposta.

## 4. Revisões

Campos recomendados: Semana, Objetivo avaliado, Avanços, Pendências, Indicadores, Bloqueios, Decisão da semana, Próxima ação e Data da próxima revisão.

## Relações essenciais

- Um objetivo pode conter várias ações.
- Uma ação pertence a um objetivo e pode apontar para uma dependência.
- Um obstáculo deve estar ligado ao objetivo e, quando possível, à ação afetada.
- Uma revisão consolida o estado do objetivo, das ações e dos obstáculos.
