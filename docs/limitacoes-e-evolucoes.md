# Limitações e evoluções

## Limitações atuais

- O assistente depende da qualidade das informações fornecidas.
- As sugestões não substituem priorização humana.
- O projeto não executa tarefas externas automaticamente.
- O caso demonstrativo usa dados fictícios e não mede resultados de uma campanha real.

## Evoluções possíveis

1. Integração com Google Calendar para blocos de rotina.
2. Automação de revisão semanal com n8n.
3. Painel de indicadores conectado a uma planilha.
4. Histórico de decisões e comparação entre ciclos.
5. Controle de permissões e templates para equipes.
6. Validação das sugestões por regras de negócio antes do registro no Notion.
